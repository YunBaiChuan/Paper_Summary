# Attention Is All You Need https://proceedings.neurips.cc/paper_files/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html

## 摘要

**最先进的序列转换模型通常都基于循环/卷积神经网络，且包含了编码器和解码器。这里序列指的是和顺序有关的数据，比如一段话；而序列转换则指的是从一个序列转换到另一个序列的过程，比如英语翻译成中文。并且性能最好的模型还通过注意力机制来连接编码器和解码器。在这个背景下，我们提出了完全基于注意力机制的网络架构，即Transformer，它完全不需要循环/卷积。在两个机器翻译任务上，我们验证了这个架构的可行性：1.在WMT 2014 Englishto-German translation task上得到了28.4 BLEU的分数，比最佳模型提高2个BLEU；2.在WMT 2014 Englishto-French translation task上得到了41.0 BLEU的分数，并且仅用8块gpu并行训练了3.5天，而且这个训练代价还只是最优模型的一小部分。这体现了Transformer的并行能力和训练代价小优势。这里NLP中的BLEU指标可以看作是CV里面的ACC，他是用词重叠来计算分数的。一般20-30为良好，30-40为优秀，并且提升1个BLEU就算显著了，提升更多的话，说明这个方法有突破**

## 1. 介绍

**循环神经网络，长短期记忆网络，带门控的循环神经网络，它们随着技术发展，已经被牢固的确定为解决序列建模和转换问题，比如语言建模和翻译问题的最先进方法。并且至今，人们还在不断突破循环神经网络和编码器-解码器架构的限制**

**循环模型通常是沿着输入和输出的符号位置进行计算，也就是顺序计算。每个位置/每一轮计算出来的ht由上一个位置/上一轮的隐状态ht与当前位置/当前轮的xt共同决定。当然，第一轮的时候一般默认上一轮/初始轮为全0张量。这种固有的自然顺序影响了序列处理的并行性，并且对于长序列来说，他的缺点会被明显放大。目前的研究是通过质因子分解技巧和条件计算来提高计算效率，并且后者还能提升模型性能。但这些方法都没能解决顺序计算这个基本问题**

**注意力机制已经在各种序列建模和变换模型等任务中，成为了非常重要的一部分。它可以无视输入或输出序列间的距离，来进行序列位置间的依赖建模。然而除了少数情况以外，注意力机制都是和循环模型结合使用的**

**在这项工作中，我们提出了Transformer。这是一种舍弃了循环，完全使用注意力机制来绘制全局输入与输出依赖关系的全新架构。它允许并行训练，并且只需要在8张gpu上训练12个小时，就可以在翻译质量上达到新的水平**

## 2. 背景

**减少顺序计算的计算量成为了很多模型的目标，比如Extended Neural GPU、ByteNet、ConvS2S。这些神经网络都基于卷积块搭建，并行计算出输入与输出位置的隐藏表示关系。不过在这些模型中，将两个任意位置的输入或输入位置信号关联起来的操作数，会随着距离的增加而增加。对于ConvS2S来说是线性的代价，对于ByteNet来说是对数代价，这就使得模型学习两个遥远位置的依赖变得比较困难。在Transformer中，我们可以通过恒定的操作数来学习位置依赖，但通过平均的注意力权重会导致有效分辨率降低，不过我们后续引入的多头注意力机制将会抵消这种影响。序列处理中的有效分辨率指的是模型对于相邻位置差异的敏感度**

**自注意力，也叫内在注意力。它是一种将单一序列内部不同位置进行关联的注意力机制，目的是为了计算序列的表示。自注意力早已成功应用在了各种任务中，包括阅读理解、抽象概括等**

**端到端的记忆网络基于循环注意力机制，而不是序列对齐循环，并且在简单的语言问答和语言建模任务中，展现出了出色的表现**

**在当时看来，Transformer是第一个完全用自注意力来计算输入与输出表示，并且不用序列对齐的RNN或者卷积的网络。接下来的章节，会主要讲述Transformer激发自注意力，并且讨论它的优势何在**

## 3. 模型架构

**大部分有竞争力的模型，都采用了编码-解码结构。这里的编码器主要是将输入的符号序列$(x_1, x_2, ..., x_n)$映射成连续序列$z = (z_1, z_2, ..., z_n)$。这里的符号序列是离散的，以"I love you"为例，就是每一个单独的字符就是一个向量，它们之间没有什么关系。通过编码器之后得到一个新的连续序列，里面的向量是有上下文关系的。之后给定z，解码器每次生成一个元素的符号序列$(y_1, y_2, ..., y_n)$。解码器生成每一个元素的时候都要看z，去找对应的需要部分。在每一个步骤中，模型都是自回归的，也就是说每生成下一个元素的时候，会先把上一个生成的元素作为输入加进来**

**Transformer遵循这一总体设计架构，对编码器和解码器采用堆叠自注意力和逐点全连接层，其具体设计如下，左边为编码器，右边为解码器**

### 3.1. 编码器与解码器堆叠

**对于编码器来说，我们堆叠串行了$N = 6$个相同的层，并且层内部采用了残差连接机制，因此每个子层输出$LayerNorm(x + Sublayer(x))$。为了方便残差连接，模型中的所有子层和嵌入层的输出都为512维度。他输入是算的自注意力，然后采用了多头注意力方法，用多个头进行并行计算，然后拼接起来得到完整的自注意力**

**对于解码器来说，我们也是堆叠串行了$N = 6$个相同的层，并且在编码器的两个子层上，又增加了中间的第三层。它主要是对编码器的输出做一个多头注意力，得到的是一个交叉注意力。当然，层内部也是用到了残差连接机制，并且我们对解码器的自注意力做了修正，防止其关注到未来的位置。具体来说就是通过掩码机制，以及输出嵌入偏移一个位置，就是往右偏移一个位置，使得当前位置i只能够依赖于 < i位置的已知输入进行当前位置的预测**

**当然，对于本图来说这是训练过程，其中Outputs部分是训练的标签，最终解码器输出结果是整个词表的预测概率分布。如果是验证过程的话，就可以再走一步，取当前位置词表预测概率中的最大值，对应的那个子词就是当前位置预测的子词。为什么说是子词？因为如果我们是预测每个单词的话，会造成很大的浪费。其实每个单词是由多个子词组成的，我们只需要用子词就可以拼出很多种单词。所以说我们每次预测也是预测子词，最终预测得到子词表，我们再根据拼接规则进行拼接，就可以得到实际预测的句子了**

### 3.2. 注意力

**注意力函数主要是将查询Q映射到一组键值对K-V上面最终得到一个输出Output，其中请求Q、键K、值V、输出Output都是向量。其中输出结果Output由值V的加权和计算得到，而每个值V的权重由请求Q与键K通过兼容性函数计算得到，这里的兼容性函数主要是算请求Q与键K的匹配程度**

#### 3.2.1. 缩放点积注意力

**缩放点积注意力，它的输入是请求Q和键K，它们的维度是$d_k$，还有个输入是值V，它的维度是$d_v$。我们计算每个请求Q和所有键K的矩阵乘法，也就是MatMul过程；接着将这些点积进行$/ \sqrt{d_k}$缩放，也就是Scale过程；然后Mask掩码可选，再接上一个SoftMax得到值v的权重；最终和值V做一个矩阵乘法得到当前输出，流程如下图：**

<img width="342" height="432" alt="image-1" src="https://github.com/user-attachments/assets/ddb9a1dc-8ee8-48d4-820f-64cdc82d7846" />

**解析一下流程，首先MatMul就是矩阵乘法算Q和K相似性的，也就是前面说的兼容性函数。然后缩放的目的主要是防止点积过大，导致SoftMax进入“饱和区”，就没有区分度了。最终输出n * n的概率分布矩阵，然后与值V做矩阵乘法得到结果**

**事实上，我们对于请求来说是同步进行计算的，也就是打包成一个请求矩阵Q，同理我们的键K和值V，也是经过打包得到的矩阵。最终的注意力函数公式如下，其实就是缩放点积注意力的公式**

<img width="757" height="88" alt="image-2" src="https://github.com/user-attachments/assets/6fbafe90-ab2a-4aef-bce5-ceef7acff0c6" />

**两种最常用的注意力函数是加性注意力和点积注意力，其中我们更倾向于使用点积注意力，并且与一般的点积注意力不同，我们采用了缩放因子$1/ \sqrt{d_k}$。从理论上来说，这两种注意力函数的复杂度差不多，但事实上点积注意力会更快，更省空间。因为它可以通过矩阵进行计算，而计算机拥有高度优化的矩阵运算逻辑**

**对于比较小的$d_k$，两种注意力机制表现类似。而对于比较大的$d_k$，加性注意力相较于传统的无缩放点积注意力来说，表现会更好。导致这个结果的原因也就是我们先前分析过的点积过大，SoftMax进入“饱和区”，导致梯度小，区分度不明显。为了克服这个缺点，才引入了缩放因子$1/ \sqrt{d_k}$**

#### 3.2.2. 多头注意力

**相较于传统的单个注意力函数来处理K, V, Q，我们发现使用不同的线性投影来处理K, V, Q一共h次的情况下，效果会很好。这个网络能够分别学到$d_k$的线性投影以及$d_k$和$d_v$尺寸。然后我们就可以对每个不同版本的K, V, Q执行并行的注意力计算，产生$d_v$维度的输出。最后将它们进行拼接，然后线性投影一遍，就可以得到最终值。结构如下图：**

**该公式相较于一般的单个注意力头，对于每个线性投影来说，他都有自己的权重，算出来是自己头的注意力，最终将所有头拼接起来，然后进行混合，也就是$\*W^O$这个输出权重矩阵，得到最终结果。因为我们每个头算出来的注意力是独立的，而要反应整个注意力，就需要将他们进行混合。本论文中采用$h = 8$也就是8个头，对于每个头来说就是$d / h = 64$个维度，并且由于每个头的维度降低，整体计算代价其实和单个注意力头差不多**

#### 3.2.3. 注意力在我们模型中的应用

**Transformer在以下方面用到了多头注意力：**

**1.在编码器-解码器注意力结构中，请求Q从上一轮的解码器得到，记忆键K和和值V从当前轮编码器得到。这个操作允许解码器的每个位置都能够参与输入序列的所有位置，它模仿了序列到序列模型中，非常典型的编码器-解码器注意机制**

**2.编码器包含了自注意力层，并且对于每个自注意力层来说，它的K, V, Q都来自于对叠层的上一层输出。这就使得编码器的每个位置它可以关注到来自于上一层中的所有位置**

**3.类似的，解码器自注意力层的每个位置也能够看到上一层中的所有位置。但额外的，我们需要阻止注意力“向左看”这一行为，也就是未来信息左流问题。这个就可以通过在缩放点积注意力结构中采用遮罩，也就是把未来信息置为$-\inf$，然后在SoftMax中，这些位置都会变成0，也就是权重为0**

### 3.3. 位置式前馈网络

**除了注意力子层，编码器和解码器中的每个层都包含有一个全连接的前馈神经网络，这个网络相同且独立的作用于每个位置。并且这个前馈神经网络由两个线性层组成，中间有一个ReLU激活函数。所以说前馈神经网络对于每个位置输出的公式如下：**

<img width="858" height="76" alt="image-5" src="https://github.com/user-attachments/assets/f2c2752b-da40-40b8-ae5d-20f9e5fb5735" />

**首先是经过线性层1，得到$W_1x + b_1$，然后经过ReLU激活函数，即$max(0, xW_1 + b_1)$，最后经过线性层2，得到输出为$max(0, W_1x + b_1)W_2 + b_2$。虽然每个位置间的线性变换相同，但层与层之间的权重不同，也就是$W_1$和$W_2$不同。我们也可以把线性变换的过程描述成两个核大小为1 * 1的两个卷积操作。还有就是输入维度和输出维度都是词嵌入模型维度，即$d_{model} = 512$，然后前馈神经网络全连接的线性变换维度，即$d_{ff} = 512 * 4 = 2048$**

### 3.4. 词嵌入和SoftMax

**和其他序列转换模型类似，我们采用词嵌入模型来将输入与输出的序列转换为$d_{model}$维度的向量。同时，我们还在解码器结尾用到了线性层和SoftMax，将解码器的输出转换为预测Token的概率分布。这里的Token指的是词源，比如前面说的子词就包含在这个里面，他是模型处理文本的最小单位。在我们的模型中，词嵌入层和SoftMax前面的线性层采用相同的权重矩阵，并且对于词嵌入层的权重来说，我们要额外$\* \sqrt{d_{model}}$，这是为了平衡嵌入层与输出层之间的梯度尺度。因为线性层采用的是有累加的矩阵乘法运算，在相同标准差初始化的情况下，线性层和嵌入层在反向传播时的梯度量级天然相差了$\sqrt{d_{model}}$倍左右**

## 4. 为什么选择自注意力

**在本章节，我们将比较自注意力层和循环层、卷积层在各个方面区别。该循环层和卷积层通常用于将输入的符号序列$(x_1, x_2, ..., x_n)$映射成连续序列$z = (z_1, z_2, ..., z_n)$，我们将比较以下三点内容**

**一是每一层的整体计算复杂度，另一个是可以并行化计算的数量，这个我们通过所需的最少顺序计算量进行衡量。第三点是网络中远距离依赖的路径长度，因为学习远距离依赖一直以来是许多序列转换任务中的难点。影响学习这种依赖关系能力的关键因素在于，网络中信号的前向和反向传播，所必须经过的路径长度。输入和输出中任意位置的结合的路径越短，就越容易学习到远距离依赖。因此，我们还比较了不同网络层中任意两个输入、输出位置间的最长路径距离，整个比较结果如下：**

<img width="1108" height="247" alt="image-7" src="https://github.com/user-attachments/assets/b7aad715-4bfe-498f-8971-038f81c20f7f" />

**首先自注意力层可以看到所有位置，并且顺序操作恒定，但是循环层就必须要$O(n)$的顺序操作。在每一层的时间复杂度这一块，当$n < d$时，自注意力层的时间复杂度才会优于循环层。为了解决这个问题，我们可以对自注意力做限制，让他只能看到邻域r内的位置，后续会仔细研究这一块**

**对于单独的卷积层来说，其核大小为k通常< n，也因此他不能够连接输入与输出的所有位置。要想实现输入与输出的所有位置都能看到的话，需要堆叠$O(n / k)$量级的卷积层，或者说堆叠$O(log_k(n))$量级的卷积层。但这会增加最大路径长度，并且卷积层的代价是循环层的k倍。通过分离卷积，我们可将时间复杂度降低到$O(k * n * d + n * d^2)$，不过当$k == n$时有，$O(n^2 * d + n * d^2)$。这相当于是我们模型中，自注意力层加上前馈神经网络层的复杂度**

**除了这些好处以外，我们的模型还有附加好处，也就是可解释性。我们检查了模型注意力的分布，单个注意力头不仅能够清晰的学习执行不同任务，而且许多注意力头还表现出了与句子语法、语义结构相关的行为**

## 5. 训练

### 5.1. 训练数据和批处理

**我们在WMT 2014 English-German数据集上，使用字节对编码（BPE）进行编码，这个编码结果大概是37000词源的共享表。这里的BPE其实就是把英语单词拆成子词，用子词进行单词的组合，可以大大节省空间。并且还是英语-德语的共享词表，因为两种语言属于同一种体系，有些数字、字符、标点、词缀一致，比分开存储要省很多空间。对于WMT 2014 English-French数据集来说，我们将36M的句子拆成了32000个词源的表。然后句子对按照序列长度进行分批，对于训练集的每个批次来说，大概是25000个标记对**

### 5.2. 硬件和时间表

**我们在一台配备了8张NVIDIA P100 GPUs的机器上进行训练。对于基础模型来说，每个训练步骤/更新一次参数需要花费0.4s，我们在这个基础模型上训练了100000次，也就是12h左右；对于大模型来说，每个训练步骤/更新一次参数需要花费1.0s，我们在这个大模型上训练了300000次，也就是3.5天左右**

### 5.3. 优化器

**我们采用Adam自适应学习率优化器，其中三个参数取$\beta_1 = 0.9$, $\beta_2 = 0.98$, $\epsilon = 10^{-9}$。它们对应的作用简单说来就是“惯性保方向，步长保大小，额外防爆0”。并且由于Transformer没有用到BN，而是采用LN（BN指的是批归一化，他是多按批进行统一归一化的；而LN指的是特征归一化，它指的是在自己本身上进行归一化，两者不同），而且网络深度还很大，所以说训练初期梯度非常大，而Adam又看重历史梯度。如果说直接用Adam训练的话，步长会越来越大，Loss会爆炸。因此训练初期就需要对学习率进行“热身”，让他按照线性增长，之后再用Adam就可以了。这里“热身”的步骤设置为4000，“热身”公式如下：**

### 5.4. 正则化

**我们采用了两种正则化方式如下：（正则化指的是防止网络过拟合的方法，包括在损失函数添加L1/L2惩罚项、Dropout，数据增强、早停机制等）**

**1.残差Dropout：我们对每个子层的输出采用Dropout，然后将它添加到下一个层的输入并进行归一化。此外词嵌入层与位置编码层相加之后，还需要经过一次Dropout才能进入编码器/解码器中。对于基础模型来说，我们设定$P_{drop} = 0.1$**

**2.标签平滑：这里取参数$\epsilon_{ls} = 0.1$，这会增加模型的困惑度，不过可以提高准确率和BLEU分数，得到更好的效果。这里标签平滑指的是对独热编码One-hot这个硬编码进行平滑，没平滑前对应位置就是答案为1，其他位置为0。训练的时候模型会尽量去逼近这个答案，可能导致模型不稳定，泛化能力差。因此就可以先算$\epsilon_{ls} / k$，然后给所有k个预测位置这个初始预测值，然后对于每个位置来说，再加上$(1.0 - \epsilon_{ls})$ * 硬编码值，就是平滑之后的独热编码One-hot了**

## 6. 结果

### 6.1. 机器翻译

**翻译时，我们主要采用了集束搜索和长度惩罚。一般的，简单的机器翻译就是用贪心搜索，每次选词库中当前位置概率最大的那个词，最后拼起来。这个好处就是简单，但这里的贪心他不一定正确，也就是说局部最优解不一定就是全局最优解。因此就采用集束搜索和长度惩罚，先说集束搜索。他有一个参数叫beam size，也就是集束尺寸，论文设置为4。他作用就是将预测概率最大的4个词作为候选，这4个词要保留整句。然后每次就在这个4个词的基础上往后延伸，算概率，最终拼接出了4个带概率的整句，选概率最大的那个整句。这里拼接算概率就是每个词的概率进行相乘得到的，这也引出了一个问题：集束搜索倾向于短词，因为这样概率会更高。所以说我们又引入了长度惩罚，对长度有0.6的惩罚因子，让长句子不被过度打压。然后还采用了检查点平均策略，也就是保存模型最后几次的参数，然后做一个平均，最终就用平均的参数作为训练好的模型，它可以提高一些泛化能力。各个模型效果如下：**

## 7. 结论

**我们提出了Transformer，这是首个完全基于注意力机制、摒弃循环层的序列转录模型，在翻译任务上不仅训练速度远超RNN/CNN架构，还在WMT 2014 English-to-German 和 WMT 2014 English-to-French translation tasks上达到了新的SOTA（英德任务上甚至超越了所有先前报告的集成模型）。未来我们将把注意力模型拓展到图像、音频等多模态任务，并研究局部注意力机制以处理大规模输入，同时探索降低生成过程序列依赖性的方向**
