# Attention Is All You Need https://proceedings.neurips.cc/paper_files/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html

## 摘要

**最先进的序列转换模型通常都基于循环/卷积神经网络，且包含了编码器和解码器。这里序列指的是和顺序有关的数据，比如一段话；而序列转换则指的是从一个序列转换到另一个序列的过程，比如英语翻译成中文。并且性能最好的模型还通过注意力机制来连接编码器和解码器。在这个背景下，我们提出了完全基于注意力机制的网络架构，即Transformer，它完全不需要循环/卷积。在两个机器翻译任务上，我们验证了这个架构的可行性：1.在WMT 2014 Englishto-German translation task上得到了28.4 BLEU的分数，比最佳模型提高2个BLEU；2.在WMT 2014 Englishto-French translation task上得到了41.0 BLEU的分数，并且仅用8块gpu并行训练了3.5天，而且这个训练代价还只是最优模型的一小部分。这体现了Transformer的并行能力和训练代价小优势。这里NLP中的BLEU指标可以看作是CV里面的ACC，他是用词重叠来计算分数的。一般20-30为良好，30-40为优秀，并且提升1个BLEU就算显著了，提升更多的话，说明这个方法有突破**

## 1. 介绍

**循环神经网络，长短期记忆网络，带门控的循环神经网络，它们随着技术发展，已经被牢固的确定为解决序列建模和转换问题，比如语言建模和翻译问题的最先进方法。并且至今，人们还在不断突破循环神经网络和编码器-解码器架构的限制**

**循环模型通常是沿着输入和输出的符号位置进行计算，也就是顺序计算。每个位置/每一轮计算出来的ht由上一个位置/上一轮的隐状态ht与当前位置/当前轮的xt共同决定。当然，第一轮的时候一般默认上一轮/初始轮为全0张量。这种固有的自然顺序影响了序列处理的并行性，并且对于长序列来说，他的缺点会被明显放大。目前的研究是通过质因子分解技巧和条件计算来提高计算效率，并且后者还能提升模型性能。但这些方法都没能解决顺序计算这个基本问题**

**注意力机制已经在各种序列建模和变换模型等任务中，成为了非常重要的一部分。它可以无视输入或输出序列间的距离，来进行序列位置间的依赖建模。然而除了少数情况以外，注意力机制都是和循环模型结合使用的**

**在这项工作中，我们提出了Transformer。这是一种舍弃了循环，完全使用注意力机制来绘制全局输入与输出依赖关系的全新架构。它允许并行训练，并且只需要在8张gpu上训练12个小时，就可以在翻译质量上达到新的水平**

## 2. 背景

**减少顺序计算的计算量成为了很多模型的目标，比如Extended Neural GPU、ByteNet、ConvS2S。这些神经网络都基于卷积块搭建，并行计算出输入与输出位置的隐藏表示关系。不过在这些模型中，将两个任意位置的输入或输入位置信号关联起来的操作数，会随着距离的增加而增加。对于ConvS2S来说是线性的代价，对于ByteNet来说是对数代价，这就使得模型学习两个遥远位置的依赖变得比较困难。在Transformer中，我们可以通过恒定的操作数来学习位置依赖，但通过平均的注意力权重会导致有效分辨率降低，不过我们后续引入的多头注意力机制将会抵消这种影响。序列处理中的有效分辨率指的是模型对于相邻位置差异的敏感度**

**自注意力，也叫内在注意力。它是一种将单一序列内部不同位置进行关联的注意力机制，目的是为了计算序列的表示。自注意力早已成功应用在了各种任务中，包括阅读理解、抽象概括等**

**端到端的记忆网络基于循环注意力机制，而不是序列对齐循环，并且在简单的语言问答和语言建模任务中，展现出了出色的表现**

**在当时看来，Transformer是第一个完全用自注意力来计算输入与输出表示，并且不用序列对齐的RNN或者卷积的网络。接下来的章节，会主要讲述Transformer激发自注意力，并且讨论它的优势何在**

## 3. 模型架构

**大部分有竞争力的模型，都采用了编码-解码结构。这里的编码器主要是将输入的符号序列$(x_1, x_2, ..., x_n)$映射成连续序列$z = (z_1, z_2, ..., z_n)$。这里的符号序列是离散的，以"I love you"为例，就是每一个单独的字符就是一个向量，它们之间没有什么关系。通过编码器之后得到一个新的连续序列，里面的向量是有上下文关系的。之后给定z，解码器每次生成一个元素的符号序列$(y_1, y_2, ..., y_n)$。解码器生成每一个元素的时候都要看z，去找对应的需要部分。在每一个步骤中，模型都是自回归的，也就是说每生成下一个元素的时候，会先把上一个生成的元素作为输入加进来**

**Transformer遵循这一总体设计架构，对编码器和解码器采用堆叠自注意力和逐点全连接层，其具体设计如下，左边为编码器，右边为解码器**

### 3.1. 编码器与解码器堆叠

**对于编码器来说，我们堆叠串行了$N = 6$个相同的层，并且层内部采用了残差连接机制，因此每个子层输出$LayerNorm(x + Sublayer(x))$。为了方便残差连接，模型中的所有子层和嵌入层的输出都为512维度。他输入是算的自注意力，然后采用了多头注意力方法，用多个头进行并行计算，然后拼接起来得到完整的自注意力**

**对于解码器来说，我们也是堆叠串行了$N = 6$个相同的层，并且在编码器的两个子层上，又增加了中间的第三层。它主要是对编码器的输出做一个多头注意力，得到的是一个交叉注意力。当然，层内部也是用到了残差连接机制，并且我们对解码器的自注意力做了修正，防止其关注到未来的位置。具体来说就是通过掩码机制，以及输出嵌入偏移一个位置，就是往右偏移一个位置，使得当前位置i只能够依赖于 < i位置的已知输入进行当前位置的预测**

**当然，对于本图来说这是训练过程，其中Outputs部分是训练的标签，最终解码器输出结果是整个词表的预测概率分布。如果是验证过程的话，就可以再走一步，取当前位置词表预测概率中的最大值，对应的那个子词就是当前位置预测的子词。为什么说是子词？因为如果我们是预测每个单词的话，会造成很大的浪费。其实每个单词是由多个子词组成的，我们只需要用子词就可以拼出很多种单词。所以说我们每次预测也是预测子词，最终预测得到子词表，我们再根据拼接规则进行拼接，就可以得到实际预测的句子了**
