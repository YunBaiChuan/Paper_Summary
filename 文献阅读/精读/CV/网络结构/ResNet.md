# Deep Residual Learning for Image Recognition https://arxiv.org/abs/1512.03385

## 摘要

**对于较深的传统神经网络来说，不太好训练。于是本文提出来一种全新的残差学习框架，用于解决较深模型不好训练的问题。并且通过在ImageNet数据集上面跑152层的残差网络（比VGG深8倍左右，并且复杂度还更低），误差达3.57%，获得了分类比赛的第一名；同时也用100层和1000层的残差网络，测试了CIFAR-10数据集**

**这个深度残差网络是当时打比赛时的一个基础，最后也是获得了包括ImageNet数据集目标检测、COCO数据集目标检测、COCO数据集分割等比赛的第一名**

## 1. 介绍

**深度卷积网络在图像识别上有很多突破性的成果，并且越深的网络可以整合更多低/中/高级的特征，很多比赛上面取得比较好成绩的模型，无一例外都很深。当我们想堆叠更多层，获得更好的效果时，阻碍出现了。这个阻碍也就是梯度消失/爆炸，我们必须得解决这个阻碍才能实现在更深的网络中，获得更好的效果**

![alt text](<Screenshot 2026-07-17 225155.png>)

**首先有个解决方案就是在网络初始化时进行归一化操作，并且在网络训练时的中间层中，引入归一化层，这可以大大解决梯度消失/爆炸这个阻碍，能将网络深度提高到10多层。但是更深层还是不行，会出现退化问题，即产生更大的误差，通过在CIFAR-10数据集上进行的测试，也可以证明这一点**

**那有没有什么网络的构造方式，能证明更深的网络是可以获得更好效果的？考虑在原先的网络中，加上恒等映射的堆叠层，此时网络更深，而且仅仅是学习如何原封不动，按道理来说效果是不会比原来差的。但实验表明他的效果反而更差了，说明问题不是出在网络结构上，而是出在如何学习上面**

![alt text](<Screenshot 2026-07-17 225212.png>)

**因此，提出了一种新的学习方式，也就是学习残差。他主要是将原先训练时需要的底层映射$H(x)$，改成另一种映射，也就是残差映射$F(x) = H(x) - x$，那么此时的底层映射其实就是$H(x) = F(x) + x$。我们只需要训练残差$F(x)$，然后在输出层添加一个恒等映射x的跳跃连接，就可以得到底层映射$H(x)$了。这种方式不仅不会增加额外参数，也不会使得训练变得更加复杂。并且在极端情况下，如果恒等映射x就是最优解，那我们要使得目标输出$H(x)$尽量接近x，就从原来的拟合x到了现在残差$F(x)$优化到0，后者会更容易实现**

**深度残差网络经过实验测试，发现它解决了退化问题，并且准确率比以往的网络都要高，而且复杂度还更低。同时也用这个网络参加了很多CV方面的比赛，并且取得了很好的成绩。这两个方面可以证明这个新的学习方式，即学习残差是一种有效的方式，并且不仅可以用到视觉方向，还可以用在非视觉方向，是一种通用的方式**

## 2. 相关工作

**ResNet的设计灵感来源于两个思想传统。一方面，在图像检索（如VLAD、Fisher Vector）和数值优化（如多重网格法）中，学习或计算残差（差值）往往比直接学习原始值更高效，这为用残差映射来拟合目标函数提供了理论先例。另一方面，“跳跃连接”在网络中的使用并非全新概念，早期的多层感知机、用于解决梯度消失的辅助分类器以及GoogLeNet的Inception模块都曾引入跨层连接。与同期提出的“Highway Networks”相比，ResNet的核心区别在于：Highway Networks使用带参数的数据依赖门控来控制信息流，而ResNet采用无参数的恒等映射，始终保持所有信息通过，让网络真正专注于学习残差函数，从而避免了门控机制可能带来的优化阻碍，使得超深网络（超过100层）的训练成为可能。**

## 3. 深度残差学习

### 3.1. 残差学习

**首先再次介绍了残差学习，以及它的公式原理。我们认为用多个非线性层进行堆叠，可以近似拟合复杂的函数，因此传统的网络就采用这种方法来拟合$H(x)$，同理我们也可以拟合残差网络中的$F(x) + x$。并且对于残差网络来说，特别是拟合$H(x) = x$这样的恒等映射，只需要拟合$F(x) = 0$即可，不需要拟合复杂的$x$**

**然后又说了一遍传统网络对于恒等映射的拟合效果很差，残差网络只需要调用很少几个非线性层为0，就可以拟合得很好。当然，目前为止都是在说残差网络主要是对于恒等映射的效果很好，但实际上大部分时候都不是恒等映射，那这时候效果又怎么样？通过实验证明，如果$H(x)$接近于x的话，即目标映射接近于恒等映射，用残差网络的效果会更好**

**因为传统网络相当于是你从0开始去拟合一个复杂函数，但残差网络是给你预设了一个起点，也就是x，即恒等映射。并且往往我们真正需要拟合的函数就在这个恒等映射x附近，所以说用残差网络效果更好**

### 3.2. 通过跳跃连接添加恒等映射

**每隔几层就可以添加一个残差学习，以图2为例。我们可以得到更详细的公式为$y = F(x, \{W_i\}) + x$，这里$W_i$表示我们可能是隔了多层，每层有一个$W_i$，那就有多个$W_i$。那图二来说，只有两层，并且里面还有激活函数$RELU$，因此这里的$F = W_2\alpha(W_1x)$，其中$\alpha()$表示经过一次$RELU$，并且可以看到最终输出的y也是套了一层$RELU$的，即$\alpha(y)$。此处没考虑偏置$b_i$，目的是让式子看着简洁**

**然后从这个结构中可以发现，跳跃连接并没有增加额外参数，也没有使得结构更加复杂。这样就方便在同等深度和参数等条件下，比较残差网络和一般网络的性能指标。不过我们可以发现，要使得公式成立，其中的$F$和$x$得是相同维度才行，那该如何保证维度是相同的呢？通常我们以$F$的维度为准（因为改变x的维度会更简单），如果此时$x$的维度与$F$相同，那就直接用恒等映射$x$；否则就在$x$上乘一个$W_s$向量，得到线性投影$W_sx$，来使得维度一致。此时公式就变成了$y = F(x, \{W_i\}) + W_sx$**

**我们还可以发现这个F是很灵活的，它依据对叠层的层数和类型，比如前面都是用全连接层为例，其实也可以用卷积层，然后层数可以是2层或者3层，甚至更多。特别的，当我们的层数为1层时，公式就变成了$y = W_1x + x$，不过目前没观察到1层时有什么特别的优势**

**为了简单起见，上述都是用全连接层做的例子。可事实上，它也可以用与卷积层，此时的$F(x, \{W_i\})$就变成了卷积残差。并且残差与恒等映射特征图的相加采用逐像素，逐通道相加**

### 3.3. 网络架构

**首先，我们受到VGG-19网络的启发，设计了一个34层的网络，主要就是用3 * 3的卷积层，然后下采样同时用到了步长stride为2的卷积层，以及3 * 3的，步长stride为2的池化层。同时设计时遵循两个准则：1.图像尺寸不变的情况下，通道数/过滤器的数量不变；2.图像尺寸h, w减半的情况下，通道数/过滤器的数量翻倍。这是为了保证时间复杂度的一致性，不至于越深的层数，计算量越大。结尾再加上一个全局池化以及1000分类的全连接，并套上softmax就设计完成了。并且可以发现我们设计的这个34层网络拥有更少的最大通道数，以及更少的计算量**

**基于上面设计的基准网络，我们在它上面插入了跳跃连接，就变成了对应的残差网络版本。这里是每个两层引入一个跳跃连接，当维度不变时就可以直接相加，否则我们就需要进行维度匹配，也就是对x进行升维。那么升维有两种方案：1.全部添加0；2.投影，用1 * 1卷积实现。对于这两种方式来说，如果图像尺寸发生了变化，那就按步长stride为2执行即可，毕竟都是下采样。三种网络架构如下：**
