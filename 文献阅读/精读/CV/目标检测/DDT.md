# Dual-Rate Dynamic Teacher for Source-Free Domain Adaptive Object Detection https://ieeexplore.ieee.org/abstract/document/11446229

## 摘要

**无源域自适应目标检测将知识从有标记的源域，迁移到没有标记的目标域，同时在适应期间限制对源域数据的访问以保护数据的隐私性。首先要明确一些概念：1.源域指的是有标注的数据，已经训练好的场景；2.目标域指的是没有标注的数据，需要应用的场景。以晴天训练好的模型为例，我们想要把他应用到雾天，如果此时直接应用的话，效果就不是很好，因为光照、颜色分布等都不一样。因此提出了区域自适应目标检测（DAOD），它通常是将源域数据和目标域数据通过特征对齐、对抗训练等方式，将他们映射到同一个特征空间。但有很多源域数据是保密的，用不了，所以说就要探索一种新的方式，也就是文章开头所说的无源域自适应目标检测了**

**现有方法主要是利用平均教师框架在目标域进行自我训练，这里讲讲平均教师框架是什么。首先这个框架名字有教师，但不仅仅只有教师，他还有学生在框架里面。对于学生来说，它主要负责学习。通过直接输入的目标域无标签图片，算出检测框，然后再根据教师给出的伪标签去计算损失，然后反向更新自己的参数。但由于它的变化很快，很容易被目标域的噪声给带偏。对于教师来说，它负责产生伪标签，而且它的参数不是通过反向传播进行更新的，而是通过EMA平滑学生过去所有时刻的权重得到的。对于无源域自适应目标检测来说，如果只让学生瞎猜，猜错一步的话，后面就会错上加错，最终导致模型崩溃。通过采用平均教师框架，学生的变化虽然剧烈，但是教师是比较稳的，它生成的伪标签中，噪声就比较小，再让学生去学习这些伪标签的话，正确率就会逐步上升了。值得注意的是，这里教师的伪标签包含有3个部分：类别、框、置信度。他首先会通过前馈神经网络生成的很多候选框，然后再经过NMS得到去重叠的结果伪标签**

**不过平均教师框架有个问题在于，它对与新兴知识的响应滞后，可能会阻碍学生对目标领域转变的快速适应。基于此问题，我们提出了具有异步EMA（AEMA）平滑的双率动态教师（DDT）框架，它实现了分组参数更新。和传统的EMA平滑相比，AEMA根据参数对捕捉域偏移的贡献大小，动态地将教师参数分成两组。这里捕捉域偏移指的是从源域到目标域，在训练中，模型逐步适应的一个过程，也就是参数转变的过程。对于贡献大的参数来说，把它们分成“快速响应组”，给这些参数较小的平滑指数，让其快速响应；对于贡献小的参数来说，将它们分成“稳定保留组”，给这些参数较大的平滑指数，使其稳定保留。并且随着训练的进行，目标域的数据在不断被学习，模型的关注点也会发生变化。我们在三个交通基准上进行了综合实验，DTT框架完成了SOTA**

## 介绍

**目标检测是cv里面一个重要的组成部分，它为很多任务做出了突出贡献。不过，对于跨训练域和测试域来说，检测头会出现退化问题。这往往是由于训练域/源域和测试域/目标域之间的光照、颜色分布等不同。而且，特殊场景的标注代价又非常大。因此提出了区域自适应目标检测（DAOD），他利用标注的源域数据以及未标注的目标域数据来训练自适应的目标域检测头**

**在实际应用中，数据安全和隐私往往会限制DAOD从源域获取标注数据。为了解决这个问题，又提出了无源域自适应目标检测（SF-DAOD），他只需要将源域训练好的模型参数，迁移到目标域中，这个迁移过程不需要用到源域的具体标注数据**

**SF-DAOD利用平均教师框架生成伪标签来训练未标记的目标域。平均教师模型在学生模型的基础上融合了教师，并且教师的参数不需要反向传播更新，而是采用对学生的历史参数进行EMA平滑进行更新，并且这个更新是同步的，整体的。这种平均教师框架已被证明对于单域学习环境中的降噪非常有价值，并且对于无源模式下来说，这种优势却带来了稳定性与适应性之间的矛盾。教师对于学生过去参数的严重依赖阻碍了其快速适应目标域的新模式的能力。因此，教师根据过时知识制作的伪标签逐渐与学生在目标领域内的适应努力相矛盾。这种持续的错位不仅阻碍了学生获取必要特定领域特征的能力，而且加剧了由伪标签导致的错误积累**

**最近的研究发现，仅仅依靠教师生成的伪标签会产生局限性。其中LPU探索了低置信度相关的教师预测伪标签，而不仅仅是依赖高置信度的伪标签；PETS则是提出了一种具有静态和动态的双教师框架来提高伪标签的可靠性；同时DRU通过动态再训练策略来减轻标签噪声。不过这些方法都没有解决一个核心问题，那就是传统的平均教师模型参数更新时的同步EMA，对于SF-DAOD来说是不够的**
