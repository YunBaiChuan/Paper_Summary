# Supervised Discrete Hashing https://openaccess.thecvf.com/content_cvpr_2015/html/Shen_Supervised_Discrete_Hashing_2015_CVPR_paper.html

## 摘要 $${F_i$$

**由于hash算法在高维的数据存储及检索中产生了比较好的效果，因此得到了广泛的研究。但随着研究发现，对于离散hash来说，他的优化很困难，这称作NP-hard。本文基于此问题，提出了监督离散hash框架进行解决，其学习目标是生成一个对线性分类最优的二进制hash编码。并且通过引入一个辅助变量，重构了目标，使其可以通过正则化的方式得到解决。这个算法中最关键的一步在于：解决与NP-hard二进制优化有关的一个正则化子问题，而这个正则化子问题又可以通过坐标循环下降得到求解。至此这个问题就可以交给计算机求解，并且这个方法适用于规模很大的数据集。我们最终在4个数据集上验证了该方法的可行性，并与当下最先进的hash检索进行了比较**

## 1. 介绍

**首先进一步介绍了hash算法在高维数据存储及检索中，为什么会如此高效？主要是因为hash算法可以将高位数据压缩成一串二进制码，大大降低了数据存储的成本；其次数据间的相似性我们可以用汉明距离进行评估，而汉明距离的其实就是两个二进制码之间对应位不同的总数，这个我们可以将两个二进制码进行异或操作，然后再算其中的1个数得到，就非常快，这对于检索来说非常有用。他这个其实有点类似于字符串hash，不过那个是对整个字符串（一维数据）进行hash编码，得到的是10进制数，并且要求检索不是相似检索，而是相同检索。也就是说不允许多个不同字符串拥有相同hash值，否则会产生hash冲突**

**在众多hash算法中，LSH算法是其中一个比较受欢迎的hash算法。他主要是通过随机映射来生成hash函数，通常是采用欧式距离进行度量，后来扩展到了各种距离。不过这个算法有一个很大的缺点在于，如果要同时保证精度和召回率的话，需要超过1000位的二进制hash编码，这大大增加了存储空间，这也是他没被广泛应用的原因**

**因此最近比较流行的是数据相关hash，这种hash算法旨在生成简短的hash编码，一般是不超过200位，用于表示数据，这种算法大大提高了存储和检索效率。与此同时，大量hash算法方面的研究集中在线性hash，也就是找到一组超平面作为线性hash函数。后面也有扩展到非线性hash的研究，并且证明可以生成更加紧凑的hash编码**

**传统的NP-hard很难解决，因此通常将这个问题进行松弛化，也就是放宽他的条件，允许取实数。比较常见的方式就是先求出实数连续解，接着阈值化/量化连续解来近似得到我们所需要的离散二元解，但一般我们处理的编码都比较长，不断累积的量化误差会使得最终结果越来越差，无法得到比较准确的解**

**事实上，当且仅当有易于解决和可扩展的求解器时，不依赖于松弛化生成二进制hash编码会更优，而这正是被很多研究所忽略的内容。迭代量化是一种降低量化误差的有效方式，他主要是对投影的训练数据采用正交旋转。但这个方法不是一步搞定的，他要预先计算出用于学习正交旋转的映射，这通常由PCA得到。这种分离式的学习方法，使得它不会是最优解**

**于是在这些背景之下，我们提出了监督离散hash框架，目的是优化二进制编码，使其变得有效和高效。并且为了利用到监督标签，我们根据线性分类来设计了相应的hash框架，保证其学习的二进制编码对分类来说时最优的。更特殊的是，这些学习到的二进制编码可以看作是原数据非线性生成的特征向量。利用监督标签，我们很容易就可以对这些二元特征向量进行分类。类似于离散增强学习，我们将原始数据非线性变换到二元空间中，然后在这个空间中进行原始数据的分类**

**为了实现这个想法，我们提出了联合优化过程，主要是联合学习二元嵌入以及线性分类。在这个方案中，一组hash函数会被同时优化，用于拟合二进制的hash编码。并且为了更好的捕获到输入数据中的非线性结构，这些hash函数会在内核空间中进行学习，并且整个联合优化过程是采用迭代的方式，主要来解决三个相关的子问题**

**其中最关键的子问题就是二进制编码优化，我们提出了离散循环坐标下降法（DCC），用来逐位生成二进制编码。通过给线性分类器选择合适的损失函数，DDC可以在封闭条件下生成最优的二进制编码。因此，整个过程非常高效，并且可以很自然的推广到大量数据集。我们将用DCC优化监督hash的方法叫做SDH，也就是论文标题**

**接着整体总结了一下introduce提到的所有关键内容，还提到了最近的图切割算法被应用在了一些经典的hash算法中。这些算法都是用二进制编码中的每一位作为训练分类器的标签。SDH与他们不同的是，它将整个二进制编码构成了一个向量，并视其为特征向量，再用这个向量进行分类器的训练。与我们同时推进的一个工作者也注意到了二进制编码优化的重要性，他们采用的是无监督离散hash**

## 2. 监督离散hash

**首先提出了多分类的预测公式，就是比较经典的那种向量形式，其中算出来的最大概率为预测的那个分类**

<img width="607" height="167" alt="image-1" src="https://github.com/user-attachments/assets/c7a6af0d-f91f-468c-b462-1121cd6257c3" />

**然后给出了我们需要优化的损失函数，这里的$F$函数是hash函数，通过$F(x_i)$我们会得到一个连续值的向量（hash编码），比如$[0.5, -1.2, 0.8, ..., -0.3]$。之后再在外面套上一层符号函数$sgn$，也就是离散约束，将其转化为二进制编码。之后再用这个二进制编码去训练$W_i$和$F$**

**传统的松弛化就是去掉外面这一层离散约束$sgn$，直接用连续值的向量，也就是连续hash值编码去训练$W_i$和$F$，得到最优解之后，再在b套一层离散约束$sgn$。但这样做的问题就是会导致量化误差的积累，使得训练的$W_i$和$F$不够准确**

<img width="692" height="190" alt="image-2" src="https://github.com/user-attachments/assets/d21e15d4-af4f-49c8-b27f-0e574941a18a" />

**于是为了解决这个问题，我们重新表述了损失函数公式。主要就是在原先的基础上，增加了新的惩罚项，这个惩罚项挺巧妙的。他主要是衡量hash函数得到的连续值向量，与我们想要得到的最优离散二进制hash之间的差异性，当惩罚系数$v$非常大时，这个公式其实就变成了(2)。并且我们可以发现，直接优化(3)这个式子，我们最终得到的二进制编码正是前面所说的联合优化的最优线性分类编码**

**但直接三个参数联合训练还是比较复杂的，因此我们可以通过固定其中的两个参数，然后集中训练第三个参数，这种方式进行不断迭代，就可以比较轻松的解决这个复杂问题了**

### 2.1. 通过非线性嵌入逼近$b_i$

<img width="478" height="70" alt="image-3" src="https://github.com/user-attachments/assets/0e4ed709-ffff-4434-9eb5-3d933dc2b701" />

**这里采用的是一种简洁又高效的嵌入学习公式，可以看到他是非线性的形式。其中$\phi(x)$是m维度的列向量，他是通过RBF核映射得到的高维向量。简单来说就是通过原数据的高维映射，来解决低维度下的线性不可分问题。然后$P^T$表示的是$P$向量的转置，这里$P$向量是$m * L$的。因此$P$转置后与$\phi(x)$相乘，就可以得到投影后固定为$L * 1$的低维度列向量了。注意这里的L刚好了我们前面的提到的hash码长度L一致**

<img width="557" height="63" alt="image-4" src="https://github.com/user-attachments/assets/db27f4ac-0a48-411f-a57c-4c14aff1faa3" />

**如果我们固定(3)中的B，就可以通过线性代数的方式求(5)，具体公式推导如下：**

$$
f(P) = ||B - P^T\phi(x)||^2
$$

$$
f(P) = Tr((B - P^T\phi(x))\ \ (B - P^T\phi(x))^T)
$$

$$
f(P) = Tr((B - P^T\phi(x))\ \ (B^T - \phi(x)^TP))
$$

$$
f(P) = Tr(BB^T - B\phi(x)^TP - P^T\phi(x)B^T + P^T\phi(x)\phi(x)^TP)
$$

**对$f(P)$求导有：**

$$
\partial f/\partial P = 0 - \phi(x)B^T - \phi(x)B^T + 2\phi(x)\phi(x)^TP
$$

**令其为0有：**

$$
2\phi(x)\phi(x)^TP = 2\phi(x)B^T
$$

$$
P = (\phi(x)\phi(x)^T)^{-1}\phi(x)B^T
$$

**推导结果与(5)一致，这里要注意一下推导时用到的线代知识：1.F范数：也就是被||包裹的那个整体，他有点类似于求向量的长度，即把矩阵中所有元素先平方再求和，最后开根；2.迹(Tr)：表示方阵主对角线上的所有元素和**

**了解这两个概念之后，有几个推导时用到的结论需要记忆：**

$$
||A||_F^2 = Tr(AA^T) = Tr(A^TA)
$$

**迹相关的矩阵求导：**

| 函数 `f(X)` | 导数 `∂f/∂X` |
| :--- | :--- |
| `tr(AX)` | `A^T` |
| `tr(X^T A)` | `A` |
| `tr(AXB)` | `A^T B^T` |
| `tr(AX^T B)` | `BA` |
| `tr(X^T A X)` | `(A + A^T)X` |
| `tr(X A X^T)` | `X(A + A^T)` |
| `tr(X^T A X B)` | `AXB + A^T X B^T` |
| `tr(X^n)` | `n(X^{n-1})^T` |

### 2.2. L2损失的联合学习

**对于(3)来说，我们的损失函数选择是灵活的，这里选择L2损失函数，也就是常用的平方损失函数，他和L2正则化类似，都用到了平方**

<img width="666" height="125" alt="image-6" src="https://github.com/user-attachments/assets/ba0b2776-b4c6-403c-baa8-c02cb5e200ab" />

**接着对(6)做了一个转化，直接把$n$个$b_i$标签整合成了B，其规模为$L*n$；$W$的规模是$L * C$；$Y$的规模是$C * n$。值得注意的是，公式中的小写形式向量都是列向量为$L * 1$**

<img width="530" height="72" alt="image-7" src="https://github.com/user-attachments/assets/e37d195d-5c96-48c1-8a1f-a0516aff20e3" />

**如果我们固定(7)中的B，就可以用线性代数算出(8)，推导如下：**

$$
f(W) = ||Y - W^TB||^2 + \lambda ||W||^2
$$

$$
f(W) = Tr((Y - W^TB)\ \ (Y - W^TB)^T) + \lambda Tr(WW^T)
$$

$$
f(W) = Tr((Y - W^TB)\ \ (Y^T - B^TW)) + \lambda Tr(WW^T)
$$

$$
f(W) = Tr(YY^T - YB^TW - W^TBY^T + W^TBB^TW) + \lambda Tr(WW^T)
$$

**对$f(W)$求导有：**

$$
\partial f/\partial W = 0 - BY^T - BY^T + 2BB^TW + \lambda 2W
$$

**令其为0有：**

$$
2BB^TW + \lambda 2W = 2BY^T
$$

$$
W = (BB^T + \lambda I)^{-1}BY^T
$$

**推导结果与(8)一致，这里推导需要注意的是有个L2正则化项需要带上，因为他也是和W有关的。**

**然后(7)在B有离散约束的情况下是很难求解的，但如果除了B以外的其他变量都固定，我们可以重写式子(7)如下：即除了B以外的W，F，Y都看作常量，只需要找与B相关的式子**

**具体推导过程如下：我们具体优化时不会关注与B无关的纯常数，因此可以去掉**

$$
-2Tr(Y^TW^TB) + ||W^TB||^2 + ν||B||^2 - 2νTr(B^TF)

**根据F范数性质可知，式中的$B$只能取$+-1$，因此$ν ||B||^2 = v * n * L$是个确定值，可以去掉。并且又根据Tr的性质，即 $Tr(A) = Tr(A^T)$，可以得到**

$$
-2Tr(B^TWY) + ||W^TB||^2 - 2ν Tr(B^TF(x))
$$

$$
||W^TB||^2 - 2Tr(B^T(WY + vF(x)))
$$

$$
||W^TB||^2 - 2Tr(B^TQ)
$$

**推导结果与(11)一致，接着我们根据(11)来引入三个辅助变量$z^T$，$q^T$, $v^T$，分别表示$B$、$Q$、$W$中的一行**

**因此就可以利用这些辅助变量，对矩阵进行分块，得到$B = [B^{'}; z^T]$，$W = [W^{'}; v^T]$，$Q = [Q^{'}; q^T]$，这里面的分号指的是上下排列，整体是一个列向量形式**

**因此利用分块来重写(11)，先是第一项**

$$
B^TW = [B^{'T}, z] [W^{'}; v^T] = B^{'T}W^{'} + zv^T
$$

$$
W^TB = [W^{'T}, v] [B^{'}; z^T] = W^{'T}B^{'} + vz^T
$$

$$
Tr(B^TWW^TB) = Tr(B^{'T}W^{'}W^{'T}B^{'} + B^{'T}W^{'}vz^T + zv^TW^{'T}B^{'} + zv^Tvz^T)

Tr(B^TWW^TB) = Tr(const + 2zv^TW^{'T}B^{'} + const)
$$

$$
Tr(B^TWW^TB) = const + 2Tr(zv^TW^{'T}B^{'})
$$

## 3. 实验

**SDH在CIFAR-10、MNIST、NUS-WIDE、ImageNet上，检索精度和MAP均优于ITQ、KSH、FastHash等主流方法**

**消融实验（Table 2）验证了“直接离散优化”优于“松弛化+量化”，尤其在长码时更显著**

**训练效率高（6万张图约1分钟），测试极快（微秒级），适合大规模检索**

**SDH生成的哈希码本身是高质量特征，用于分类时准确率超过原始GIST特征**

## 4. 结论

**SDH通过直接离散优化，避免了量化误差，在效率与精度之间取得良好平衡，是一个通用的监督哈希框架**
