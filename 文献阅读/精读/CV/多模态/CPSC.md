# Multimodal Learning on Low-Quality Data with Conformal Predictive  Self-Calibration https://arxiv.org/abs/2605.03820

## 摘要

**多模态学习通常面临数据质量低的挑战，这主要体现在模态不平衡和噪声损坏这两个方面。对于前者来说，主要是训练上的问题，模型会偏向更容易学习的强势模态，而忽略弱势模态，比如偏向画面而忽视音频。这在强势模态失效的时候，模型的性能就会急剧下降，因为它根本没好好学习弱势模态。对于后者来说，主要是数据上的问题，指一个或多个模态中引入了噪声，这些被污染的模态会给模型提供错误信息，如果模型不加辨别的进行融合，就会被噪声误导，导致预测出错。一般来说，这两个问题都是各自单独解决的，但我们认为这两个问题有一个共同的根源，那就是学习过程中模态和实例的可靠性对于预测的不确定性。简单来说就是模型不知道样本中哪个模态可靠，以及样本本身的有多少可靠，这种不确定性导致了多模态学习效果不是很好。据此本文提出了一个统一框架，名为符合预测自校准（CPSC），它利用符合预测使得模型具备即时执行自引导校准的能力**

**我们提出的CPSC核心在于一种新颖的自校准训练循环，它无缝集成了两个关键模块：1.表示自校准，它将单峰特征分解为多个分量，有选择地融合了符合预测器识别的最稳定特征，以增强特征的弹性；2.梯度自校准，它根据实例可靠性分数将反向传播期间的梯度流重新校准，将优化引向更值得信任的方向。此外，我们还给符合预测器设计了一种自我更新策略，以确保整个系统在训练的过程中一起进化。同时在模态不平衡以及噪声影响下对6个基准数据集进行广泛的实验表明，我们提出的CPSC比目前最好的模型表现还要更好，实现了SOTA**

**总的来说，我们所做的贡献有以下三点：1.提出了CPSC框架，它用一种统一的、模型无关的视角，解决了多模态学习问题。并且从预测不确定性的角度将模态不稳定和噪声污染联系在了一起，方便共同解决；2.提出了表示自校准和梯度自校准模块，它有效地将符合预测（CP）整合进了多模态训练核心中，在特征表示和梯度优化中引入了自校准机制；3.提供了广泛的实验和理论分析，表明了CPSC在各种低质量数据中实现了多模态学习的SOTA**

## 2. 相关工作

**在实际的多模态学习应用中，低质量数据（主要表现为模态不均衡和数据噪声）是一个普遍存在的挑战。早期的研究方法主要依赖静态融合策略，如加权平均或门控机制。随着研究的深入，近期的工作开始转向动态调节机制：一方面，部分研究通过梯度操纵来平衡各模态间的学习速度，以防止单一模态主导训练；另一方面，另一些研究则致力于设计鲁棒的融合架构，或显式地为模态可靠性建模，以在融合过程中降权不可靠的信号。然而，现有方法大多是为特定问题定制的解决方案，缺乏一个能够统一处理模态不均衡与噪声干扰的通用机制**

**预测不确定性是可靠机器学习中的一个核心概念，用于量化模型对其输出缺乏信心的程度，已广泛应用于视频理解、跨模态检索和自动驾驶等视觉与多模态任务中。在多模态学习中，不确定性估计常被用来提升融合的鲁棒性，典型做法是在晚期融合中对模态进行加权，或在中间层引导融合过程。然而，这些方法依赖于特定的模型设计和先验假设，缺乏通用性。相比之下，本文提出的CPSC框架采用符合预测（Conformal Prediction），以模型无关（model-agnostic）和分布自由（distribution-free）的方式实现预测不确定性估计，从而克服了上述局限**

**符合预测（CP）是一个统计框架，能够生成具有覆盖概率保证的预测集合，即以用户指定的概率确保真实标签被包含在该集合内。由于其模型无关的特性，CP已在风险控制、异常检测和大语言模型等领域得到广泛应用。然而，CP在多模态学习中的应用仍处于起步阶段，现有工作主要将CP以“事后”方式应用于已训练好的模型，例如在训练完成后为多模态输出构建预测集合。少数研究开始尝试将CP融入训练过程（如在损失函数中引入CP）。与这些工作相比，本文提出的CPSC框架开创性地构建了一个自校准训练框架，能够在特征表示层面和优化梯度层面同时进行动态调整**

### 3.2. 符合预测器的构造

**从CPSC框架图中可以看到，它将自校准机制引入到了多模态训练的各个流程中。给定一个多模态数据集$\mathcal{D} = \{(x_i^m, y_i)\}_{i = 1}^N$，其中m表示该数据x拥有m个模态。我们首先随机将其分成两个具有相同分布的两组数据，即训练集$\mathcal{D}_{train}$和校准集$\mathcal{D}_{cal}$。该框架通过两个关键阶段运行：1.热身训练阶段，它主要是在训练集$\mathcal{D}_{train}$对多模态模型$f_{\theta}$进行初始化；2.自校准训练循环。总的来说，本框架创造了一个闭循环系统，模型随着预测不确定性不断发展的理解来不断自校准**

**具体来说，在自校准训练循环中，对于每一次训练迭代t，训练步骤如下：1.提取单峰/模态特征，然后基于目前的CP模型进行可靠性评估，并应用表示自校准（RSC）；2.融合校准特征并进行预测；3.在参数更新之前，使用CP可靠性分数来应用梯度自校准；4.更新模型参数从$\theta_t$到$\theta_{t + 1}$；5.执行符合预测器更新，以刷新下一轮迭代的CP模型**

**在开始自校准训练之前，我们先执行了热身训练来初始化CP模型。令$f_{\theta} = \{E_{\theta_1}^1,E_{\theta_2}^2, ..., E_{\theta_M}^M, F_{\theta_f} \}$表示我们的多模态模型，其中$E^m$表示特定模态的编码器，$F$表示融合分类器，也就是融合同一个样本的多个模态之后，进行分类预测。整体的训练优化目标如下：**

**其中$\mathcal{L}_{CE}$表示交叉熵损失函数，该式的优化目标在于找到一组参数$\theta$，使得模型在整个训练集上的平均交叉损失熵最小。我们将预热阶段设置为$t_0$，初始化的CP模型参数表示为$\theta_{t_0}$。热身结束后，我们进一步用校准集$\mathcal{D}_{cal}$来初始化参数。对于$\mathcal{D}_{cal}$中的每一对$(x_i, y_i)$，我们计算其对应的不及格分数$s_i = s(x_i, y_i)$，并且得到初始的分位数$\hat{q}_{t_0}$**

### 3.4. 梯度自校准

**在获得最终预测$\hat{y} = F(\{\tilde{h}^m\}_{m = 1}^M)$之后，我们同时计算多模态的交叉损失$\mathcal{L}_{CE}(\hat{y}, y)$以及单模态的交叉熵损失$\mathcal{L}_{CE}^m(\hat{y}^m, y)$。然后在反向传播之前，我们通过梯度校准来引导优化朝着更值得信赖的方向进行**

**为了实现模态梯度校准，我们首先需要量化不同模态下每个训练实例的可靠性。通过符合预测，我们获得了基于统计的可靠性分数，它反映了每个样本与当前模型对于多模态协同的理解。具体来说，对于当前批次$\mathcal{B}$中，具有多模态的每个训练样本，我们计算每个单模态分类器输出的可靠性分数。我们不用真实标签$y$，而是将多模态预测标签$y'$作为当前模型协同识别的判别标准。也就是说用模型预测的结果来作为标准，那这里就可能出现一种情况：预测标签$y'$和真实标签$y$不一致，也就是预测错误，这里仍然使用错误的标签，会不会导致训练出问题？答案是不会，我们这里其实只是通过融合预测结果来判断每个模态和融合差距，从而改变模态梯度，使其朝向融合的方向，而不是自己瞎预测。最终的预测结果会由整体的损失来控制，他这里只管协同的稳定性。接下来的CP过程就和前面RSC里面的CP过程类似，最终得到描述m模态协同差异的单模态可靠性$\rho^m$如下：**

## 4. 实验

### 4.1. 实验配置

**论文在6个涵盖4种模态（RGB、深度、音频、文本）的多模态数据集上评估CPSC，其中CREMA-D、AVE、Kinetics-Sounds用于测试模态不均衡场景（报告多模态及单模态准确率），SUN RGB-D、NYU Depth V2、MVSA-Single用于测试噪声鲁棒性场景（在干净及不同强度高斯/椒盐噪声下报告多模态准确率）；实现上，音频-视觉任务采用声谱图输入，RGB-深度任务使用ResNet18提取特征，图像-文本任务使用ResNet152和预训练BERT，RSC模块的平衡因子设为λ₁=0.8、λ₂=0.2**

### 4.2. 模型比较

**在模态不均衡场景下，CPSC在三个音视频数据集（Kinetics-Sounds、CREMA-D、AVE）上均显著优于ReconBoost、MMPareto、LFM、InfoReg、DGL、ARL和IPRM等近期方法，尤其在AVE上多模态准确率比ARL提升约5%；在噪声鲁棒性场景下，CPSC在MVSA-Single和SUN RGB-D上无论干净数据还是高斯/椒盐噪声下均超越EAU、ECML、NLC等基线，且随着噪声增强其性能下降幅度最小，表明RSC模块通过抑制污染特征分量、GSC模块通过降低不可靠样本的优化权重，共同赋予模型更强的抗噪能力**

### 4.3. 进一步分析

**消融实验表明，RSC和GSC两个模块各自都有提升，RSC对噪声场景贡献更大（因为直接过滤噪声特征分量），而GSC对模态不均衡场景更关键（通过梯度调制平衡各模态学习）；RSC模块内部，一致性约束和多样性约束缺一不可，前者保证分量不离谱、后者保证分量不重复，二者共同作用效果最佳；GSC模块与SGD、Adam、AdaGrad等不同优化器搭配均有效，说明其优化器无关的通用性；符合预测器若更新间隔过长或跳过预热阶段，性能都会明显下降，说明CP必须随模型协同演化且从可靠基础开始校准；特征可视化（t-SNE）显示，CPSC学到的音频和视觉特征类内更紧凑、类间更清晰，明显优于基线方法；可靠性分数分布也证实，CPSC训练后的模型对预测的置信度更合理，有效缓解了盲目自信的问题**

## 5. 结论

**本文提出了符合预测自校准框架（CPSC），用于解决多模态学习中由模态不均衡和数据噪声导致的低质量问题，该框架通过表示自校准（RSC）在特征层面筛选可靠分量，通过梯度自校准（GSC）在优化层面调制梯度，两者协同工作有效提升模型在低质量数据上的性能；大量实验验证了其优越性。未来工作将探索将该框架扩展到其他更具挑战性的多模态场景**
