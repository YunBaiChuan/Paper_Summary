# Imagine-then-Plan: Agent Learning from Adaptive  Lookahead with World Models https://arxiv.org/abs/2601.08955

## 问题

**基于大语言模型（LLM）的智能体在处理复杂、长时序任务时，通常只依赖当前观察和历史交互记录来做决策，缺乏对“未来”的预见能力。这种“浅层接地”（shallow grounding）导致智能体无法提前预判行动的后果，容易在复杂任务中出错**

**世界模型（World Model）虽然可以模拟环境动态，帮助智能体“想象”未来，但现有方法要么使用固定步长的推演，要么只在单步验证中使用。这种僵化的方式无法适应不同任务和不同阶段对“想象深度”的差异化需求——简单行动上过度推演浪费计算，关键决策上推演不足又容易失败**

## 方法

**本文提出 Imagine-then-Plan (ITP) 框架，让智能体通过世界模型进行自适应前瞻，在决策前先“想象”未来轨迹，再根据想象结果规划行动。核心包括：**

**1.自适应前瞻机制：智能体根据当前任务进度和状态，动态选择“想象”的步数。关键决策多想象几步，简单行动少想象甚至不想象，在性能和计算成本之间取得平衡。这被形式化为一个新的部分可观察与可想象马尔可夫决策过程（POIMDP）**

**2.两种实现变体：ITP₁（训练-free）：在推理时，智能体通过“选择想象步数 → 用世界模型想象未来 → 反思想象轨迹 → 生成行动”的流程进行决策，无需额外训练即可提升性能；ITP_R（强化训练）：通过在线强化学习，训练一个独立的 K-head 预测器，让智能体自己学会“什么时候该想象、想象多深”。训练分为伪标签生成→有监督预热→在线A2C优化三个阶段**

**3.世界模型：基于LLM微调得到，用于模拟环境动态，根据当前状态和动作预测下一步状态**

## 结果

**在ALFWorld（家务）、ScienceWorld（科学实验）、WebShop（网络购物）、StableToolBench（工具调用）四个具有代表性的智能体基准上，ITP均显著优于强基线方法。使用Qwen3-8B作为基座模型时，ITP_R在ALFWorld上的成功率达到 88.57%，相比最强的训练基线IWM（82.14%）提升了6.43%。同时，自适应前瞻相比固定步长前瞻，在计算成本更低的情况下取得了更高的成功率**

## 亮点

**问题洞察深刻：精准定位了LLM智能体“缺乏未来预见能力”的核心局限，并提出了有针对性的解决方案**

**自适应机制设计巧妙：让智能体自己决定“想象多深”，避免固定步长的僵化和浪费，实现了性能与效率的平衡**

**框架通用性强：提供了训练-free和强化训练两种变体，适用于不同场景。实验结果也表明ITP对不同基座模型（Qwen、Llama、DeepSeek）具有较好的适应性**

## 不足之处

**评估环境局限：论文目前主要在文本交互环境中验证，能否泛化到多模态或真实机器人场景还有待探索**

**推理开销：世界模型的想象过程会带来额外的推理时间和计算成本，虽然自适应机制降低了部分开销，但在实时性要求高的场景中仍需进一步优化**

## 个人感悟
