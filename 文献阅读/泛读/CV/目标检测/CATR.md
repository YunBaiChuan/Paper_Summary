# Category-Aware Differential Token Transformer for  Weakly Supervised Object Localization in  Optical Remote Sensing Images https://ieeexplore.ieee.org/document/11520631

## 问题

**弱监督目标定位（WSOL）旨在仅用图像级别的类别标签（而非昂贵的边界框）来训练模型定位目标。在光学遥感图像（ORSIs）中，由于目标与背景在结构上相似、语义上容易混淆，现有的Transformer-based WSOL方法容易产生注意力噪声——即模型错误地将注意力分配到与目标无关的背景区域，导致定位不准确或不完整**

## 方法

**本文提出一个基于类别感知差分令牌Transformer的WSOL方法，核心在于通过差分机制抑制注意力噪声。主要包含三个部分：**

**Transformer编码器：作为主干网络，提取图像的全局特征**

**基于差分注意力的定位解码器：引入多个类别令牌（每个类别一个），通过交叉注意力与图像块（patch）特征交互，提取类别特定的定位图；核心创新是差分注意力（Differential Attention）：将类别令牌投影到两个独立的子空间，分别计算两个注意力图，然后用其中一个减去另一个（A = ReLU(A1 - λ*A2)）。这种“减法”操作可以抵消两个子空间中共享的“共模噪声”（即背景干扰），从而突出类别判别区域；引入对比损失，强制两个子空间的查询向量（Q1和Q2）关注互补区域（一个偏向目标，一个偏向背景），增强差分效果**

**自适应特征权重（AFW）模块：估计每个注意力头的重要性，对来自不同层和不同头的注意力图进行加权融合，过滤掉那些仍然关注背景的噪声头**

## 结果

**在两个光学遥感图像定位基准数据集（C45V2和PN2）上，该方法取得了 65.14% 和 65.35% 的 MaxBoxAccV2 分数，优于其他WSOL方法。特别是在 Conformer-S 骨干网络上，相比 MCTFormer 基线，在 PN2 数据集上的 Box50 指标提升了超过 13%**

## 亮点

**问题针对性强：精准定位了WSOL在遥感图像中的核心痛点——注意力噪声，并提出了差分注意力机制来针对性解决**

**方法简洁有效：通过两个注意力图的“减法”来抑制背景噪声，并在实验（Fig.8）中验证了A1和A2确实分别关注前景和背景区域**

**工程化设计完整：除了核心模块，还设计了AFW模块来进一步处理通道噪声，使得整体方案更加完善**

## 不足之处

**计算复杂度略有增加：相比MCTFormer，参数量和计算量（MACs）略有提升，推理速度稍有下降（但仍满足实时要求）**

**密集目标处理困难：论文自己指出，当多个目标紧密排列时，由于缺乏实例级监督，模型仍难以将单个目标分开，导致定位结果不够精确**

**这篇论文和之前读的 RRL 有异曲同工之妙——都是通过“差异化”的策略来提升模型能力。RRL 是对特征图进行“旋转对齐”，这篇则是对注意力图进行“差分抑制”。它们都在尝试用简洁的数学操作，解决一个具体且普遍的问题**
